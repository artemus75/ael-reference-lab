# AEL Reference Lab

Public reference implementation for the Architecture Engineering Lab.

This repository is the public publication target for selected, reviewed, and
sanitized Architecture Engineering Lab material.

## Repository Role

This repository is intended to contain:

- public reference implementation material
- sanitized infrastructure examples
- reproduction guides
- public architecture documentation
- example configuration without private environment data

Private lab implementation details, raw evidence, claims, reviews, agent state,
article drafts, and internal architecture remain in the private
`architecture-engineering-lab` repository.

## Promotion Model

Content is promoted into this repository only after explicit human approval.

Promotion must preserve the boundary between:

- private lab canon and raw evidence
- public reference material suitable for publication

No secrets, credentials, private hostnames, internal IP addressing, or
environment-specific operational evidence should be committed here.
